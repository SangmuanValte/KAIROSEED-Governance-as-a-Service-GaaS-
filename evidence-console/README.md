# KAIROSEED Evidence-Driven Deployment Console

Single-file offline prototype built from the Evidence Payload / Asset Registry design.

## Run

Open `index.html` in a modern browser.

## Scope

This prototype demonstrates:
- evidence-pipeline visualization
- registry maturity states
- local receipt structural checks
- production-evidence policy checks

It does **not** establish:
- cryptographic signature validity
- durable ledger correctness
- external artifact integrity
- independent attestation
- production authorization

Claim <= Evidence <= Established Scope.
