# 🌱 Kairoseed

A quiet system for reflection, not productivity.

## When to use Kairoseed

Use this system when:
- You feel mentally overloaded or unclear
- You are stuck in thought loops or pressure
- You need to slow down without losing direction

Kairoseed is not for doing more.

It is for returning to clarity before action.

## Philosophy

- Favor restraint over expansion
- Preserve human judgment
- Permit non-action
- Avoid urgency and pressure

## Features

- Selah Check (non-directive reflection)
- Journal memory (local storage)
- Weekly theme observation (LLM-assisted)

## Run locally

```bash
pip install -r requirements.txt
streamlit run ui/app.py
```

## Notes

This system does not optimize for output, speed, or engagement.

Silence is a valid outcome.

## First Experience

When you open Kairoseed:

1. You are not given tasks  
2. You are not asked to optimize  
3. You are invited to pause  

The system begins with a Selah Check:
- A simple prompt
- No pressure to respond perfectly
- No requirement to act

From there, the system gently surfaces patterns over time through journaling and observation.

There is no forced outcome.

Only clarity, if it comes.
