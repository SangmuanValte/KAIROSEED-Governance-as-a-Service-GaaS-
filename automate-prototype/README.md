# automate-prototype — research → prototype → verify → evidence

Quickstart
1. Read HAB-001: the verification pattern in .github/workflows/hab-001-auto-trigger.yml
2. Create a small prototype under experiments/<name>
3. Add a verification campaign (scripts/verification_instrument.py)
4. Open a PR — the HAB-001 workflow will run and post evidence.json

Contribute
- See CONTRIBUTING.md for how to add campaigns, assertions (MIN/MAX/RANGE), and evidence schema.
