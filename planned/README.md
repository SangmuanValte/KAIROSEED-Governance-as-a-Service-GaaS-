# Planned / Unverified Components

This directory is intentionally separate from confirmed implementation.

Planned work includes:

- independent verification service/process;
- durable evidence store with integrity protection;
- atomic single-use authorization consumption;
- production identity and credential binding;
- complete mediation adapters for external tool systems;
- concurrency and distributed replay tests;
- dependency locking and supply-chain provenance;
- deployment admission and rollback automation;
- dedicated TypeScript test suite for `src/kairoseed.ts`.

Nothing in this directory should be described as currently implemented merely because a design or interface exists.
