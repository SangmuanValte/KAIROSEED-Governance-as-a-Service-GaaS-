# KAIROSEED — governance-first primitives

## Goal
- Define invariants and delegation patterns so execution is auditable and authority is never implicitly coupled to executors.

## What to read first
- governance.md (principles)
- invariants.md (how to write machine-checkable invariants)
- examples/ (transformations of real workflows to follow KAIROSEED)

## How to contribute
- Propose an invariant as a PR with: description, threat model, reproducible verification script, expected evidence.json.
